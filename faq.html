FAQ

Everything you need to know about installing and updating apps here.

Safety & Trust

Are these apps safe to install?

Yes. Every APK is built and released by the developer (rainkidz) and hosted on GitHub Releases — a platform with full audit logs. Each app page shows a SHA-256 fingerprint; after downloading you can verify the file matches what's published here.

Why does Play Protect show a warning?

Google Play Protect flags any APK that isn't installed through the Play Store, including perfectly safe sideloaded apps. This is a generic warning, not a verdict on the app. Review the fingerprint on the app page, then tap Install anyway if you're comfortable.

How do I verify a downloaded APK?

Open the app's detail page, copy the SHA-256 fingerprint, then hash the file on your computer:

Windows:  (Get-FileHash app.apk -Algorithm SHA256).Hash
macOS:    shasum -a 256 app.apk
Linux:    sha256sum app.apk

If the values match, the file is intact and authentic.

Installation

How do I install an APK?
  1. Download the APK from the app page (tap the button or scan the QR code).
  2. Open the downloaded file from your notification shade or file manager.
  3. If Android blocks it, tap Settings and enable "Allow from this source" for your browser or file manager.
  4. Tap Install.
What is "unknown sources"?

Android only auto-installs apps from the Play Store by default. "Install from unknown sources" is a per-app permission that lets you install APKs you downloaded yourself — like browser downloads, email attachments, or files from GitHub. You grant it once per source app.

Do I need Google Play Services?

No. All apps here run without Google Play Services — they're pure Android apps. They work on de-Googled devices too.

Updates

How do updates work?

Each app checks for a new version on launch (via a small JSON file on this site). When a newer version exists, the app shows a dialog with the changelog and an Update button — tapping it downloads the APK automatically and Android prompts you to install it.

Why can't the Play Store update these apps?

These apps are distributed directly (sideloaded), so the Play Store has no record of them. That's why each app includes its own update checker. Some apps may also be available on the Play Store separately — check the app page for a Google Play link if one exists.

Where can I find older versions?

Each app's detail page has an Old versions table with every past release. Older builds are also always available on GitHub Releases. Only sideload an older version if you know what you're doing — the app may prompt you to update again.

Technical

What Android version do I need?

Android 7.0 (API 24) or newer. Most phones from 2017 onward are supported.

How big are the downloads?

Each app page shows the exact APK size before you download. Nothing is hidden — the size shown is the file you get.

Is there a QR code to download on my phone?

Yes. Open an app's detail page on your computer, tap Show QR, and scan it with your phone's camera to download directly on the device.
