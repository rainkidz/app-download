Cara Install

  1. Pilih aplikasi, tap Download APK.
  2. Buka file APK yang sudah terunduh.
  3. Kalau muncul peringatan, aktifkan "Izinkan install dari sumber ini" untuk browser Anda.
  4. Tap Install, selesai.

Aplikasi di luar Google Play tidak bisa update otomatis dari Play Store. Setiap aplikasi di sini punya pemeriksa update internal — Anda akan dapat notifikasi saat versi baru tersedia.
