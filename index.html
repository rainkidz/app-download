How to Install

  1. Pick an app and tap Download APK.
  2. Open the downloaded APK file.
  3. If a warning appears, enable "Allow from this source" for your browser.
  4. Tap Install, done.

Apps outside Google Play cannot auto-update via the Play Store. Every app here has a built-in update checker — you'll be notified when a new version is available.

FAQ

Are these apps safe to install?

Yes. Every APK here is built and released by the developer (rainkidz), hosted on GitHub Releases, and includes a SHA-256 fingerprint on each app page so you can verify the file after downloading.

Why does Play Protect show a warning?

Play Protect warns about any app that isn't installed through the Play Store. This is normal for sideloaded apps. You can review the SHA-256 fingerprint on the app page, then choose to install anyway.

How do updates work?

Each app checks for new versions on launch and shows a dialog with the changelog. Tap Update, the APK downloads automatically, and Android prompts you to install it.

Where can I find older versions?

Open an app's detail page — the "Old versions" table lists every release with a direct download link. Older builds are also on GitHub Releases.
